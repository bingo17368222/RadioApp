更新内容 v3.1.275

  • 修复：扩展取数对一年前历史日期（如 2025-05-13）返回空。
    根因：API 对一年前日期返回空列表，而 URL 构造完全依赖 savedList 提取时间段；savedList 为空或为跨天数据时无法构造任何节目，取数直接"返回空"。
    现改为：savedList 无法提取时间段时自动使用默认 8 档时间段模板（0000_0700 … 2100_2400），pathPrefix/stationPart 从当前播放节目 URL 推导兜底，保证历史日期也能持续构造节目。
  • 修复：URL 构造后全部去重失败、取数永不推进。
    根因：days_fetched 在列表刷新/播放日期变化时被清零，取数永远从 offset=+1 重复构造已覆盖的日期（构造 URL 与 preCacheList 已有完全相同 → 全部去重失败 → size 不变即中断）。
    现改为：fetchMoreDaysForPreCache 改为多天循环推进——单日无新增（API 空 / 构造 URL 全部已覆盖 / 全部被过滤）时自动尝试下一天，直到找到新增节目或达到 15 天上限；已覆盖的时间段明确记日志后跳过，不再死等在同一天。
