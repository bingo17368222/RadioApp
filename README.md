# RadioApp（就AI听）

河南地方电台节目回放助手（Android）。自动把整期节目切成干货/水货分段，
播放时自动跳过歌曲、广告等水段，并生成字幕。

## 主要功能

### 节目单（首页「往期节目」）
- 顶部选择电台与日期，「今天」回当日、「刷新」重拉节目单
- 每条节目显示：标题、播出时间、时长（X分钟），分段生成后追加片段数（Y片段）
- 状态徽标：不喜欢、已缓存、完整字幕/部分字幕、无需预处理、正在播放
- 片段数读取多级回退：分段分析表 → 真实分段表 → 内存 → episode_info 段数字段 →
  按音频链接反查同节目另一版本（修复 ID 断层导致的"有分段只显示已缓存"）

### 播放页
- 主进度条 + 缓存进度细条
- 中央控制：上一片段 / -15秒 / 播放暂停 / +15秒 / 下一片段
  （快进快退秒数 5/10/15/30/60 可设置）
- 节目导航：上一节目 / 下一节目，按播放计划切换
- 「下一片段」：跳到当前分段结尾；最后一个分段时自动跨到下一节目首个干货段
- 开启「自动跳过水分」后，水货段自动跳过，点播水段也会跳走
- 片段列表旁入口查看播放计划 / 播放历史 / 字幕开关

### 自动分段（三层分段）
1. 第一层：音频指纹滑动窗口快筛（相似度 0.70），直接命中已知水货片段；
   无指纹库时回退 VAD+YAMNet 全流程
2. 后续层：Silero VAD 粗分语音/静音，YAMNet 语音区间密集分类、静音区间稀疏采样，
   指纹二次判定召回（阈值 0.82），窗口精修边界（±1.5秒）
3. 防误判（v3.2.55）：频谱比值不再一票判干（需语音概率 > 0.15）、
   强语音保护门槛 0.40→0.55、分析失败区间不再默认判干货

### 长按节目管理菜单
标记/取消不喜欢、删除字幕、删除缓存、标记/取消无需预处理、删除分段；
各菜单项按节目当前状态出现

### 播放计划与连播
- 播放计划：以当前节目为起点排后续待播清单；手动/自动切换节目后都会重建；
  本地缺当日节目单时自动联网补拉当日及后续 3 天
- 连续播放：播完自动续播下一节目；连续多个预生成 PCM 通知已合并为单条，不再挤掉播放通知
- 不喜欢的节目不进播放计划

### 启动续播
开启「播放记忆」后，启动弹出「是否继续播放上次的节目《标题》？」；
标题自带书名号时不会重复包裹（v3.2.49 修复双重书名号）

### 音频指纹管理（设置 → 音频指纹管理）
- 指纹数量统计；批量测试（全指纹 PCM 匹配测试）
- 指纹分组管理（可重新计算分组）、指纹分类管理
- 指纹素材来自分段中「添加为水分指纹」保存的重复片段，
  用于第一层快筛与二次判定

### 缓存与预处理
- 启用预缓存 + WiFi 预缓存；预缓存数量、预缓存音频缓存上限（GB，超限自动清最旧）
- 音频预处理（提前解码）、预分段、预先生成字幕
- 巡逻预生成完整版 PCM（按序补齐近期节目分段所需数据，不再跳过优先节目）；
  PCM 缓存上限（GB）超限自动清理
- 设置页底部：缓存总大小、清理缓存、PCM解码缓存管理

### 其他设置
AI分段模型、字幕生成方案、音频焦点、通知样式（标准/紧凑/极简）、
界面风格、自定义颜色、不喜欢的节目列表、应用图标（4 款可切换，默认广播塔）

## 分段合并规则
- 连续干货段合并上限 10 分钟（DRY_MERGE_CAP_MS，v3.2.47 由 6 分钟放宽）
- 连续水货段合并上限 10 分钟（v3.2.50 由 5 分钟放宽）
- 水货段间隔 ≤ 20 秒也会合并；过短碎段并入相邻段

## 通知与预处理
- 预生成 PCM 进度固定单条通知，不堆积、不挤占播放通知
- 巡逻预处理：近节目缺资源时按序分段，不再跳过分段优先级更高的节目
