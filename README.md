# 就AI听（电台回放助手）

> Android 电台回放工具：回听河南地方电台节目，自动分段、跳过水段、生成字幕。
> 应用名：就AI听

## 项目简介

「就AI听」是一款面向河南地方电台的回放助手 App，帮助用户在任意时间回听错过的广播节目。
核心能力是**自动分段**：把一档节目切成"干货段（说话内容）"与"水段（废话/广告/预告）"，
并可一键跳过水段、直达干货；同时支持自动生成字幕、指纹识别重复片花、WiFi 预缓存等。

## 主要功能

### 节目回放
- 按电台 + 日期浏览节目单，点击节目即回听；支持日期切换与"今天"快捷入口
- 播放页支持拖拽进度、点击分段快速跳转、调节播放速度、连续播放
- 播放计划：查看后续待播节目并一键切换；播放历史：记录上次播放位置一键续播

### 分段管理（长按节目弹出菜单）
- **删除分段**：清除该节目所有分段与分析数据，需要时重新生成
- **删除字幕**：删除后重新生成字幕
- **删除缓存**：清理已缓存的音频、字幕与 PCM
- **标记无需预处理**：该节目不再自动分段，录完即走
- **标记不喜欢**：每天同名节目不再突出显示

### 智能分段（就AI听方案）
- 三层架构：音频 VAD 快筛 → 内容关键词判定 → 音频指纹二次审核召回
- 支持引擎选择：就AI听、阿里 MNN-LLM、音频分段（VAD + YAMNet）
- 分段时长约束硬校验（`SegmentGenerator.enforceHardRules()`）：时间轴连续、无同类型碎段、
  干货≤30分钟、水段≤5分钟、标签合法

### 自动跳过
- 自动跳过水段：播放到水货段自动跳到下一段干货
- 自动连播：当前节目播完自动续播下一个节目

### 字幕
- 自动生成字幕并跟随播放滚动；支持按需重新生成

### 缓存与预下载
- WiFi 下自动预缓存当天/次日要听的节目
- 可配置缓存上限，并在设置中清理音频、字幕、PCM 等各类缓存

### 指纹识别
- 生成节目音频指纹，自动识别并区分重复片花/片尾与本段干货
- 支持"添加为水分指纹"素材管理，用于干货二次判定

## 版本里程碑（部分）

- **v3.1.256（当前）**：修复跨天节目排列错乱导致的"早间跳早间"。跨天节目 ID 无数字序号，排序时被错误排到同日期块末尾，导致刚播完早间档后播放计划跳过当天其他档位、跳跃数日直连下一个早间档。现按节目标题归类到其固有播出时段，跨天早间档可自然衔接当天后续节目
- **v3.1.246**：修复后台连续播放自动切集时节目未写入播放历史的问题（历史记录改由播放服务在切集时就地写入，不再依赖前台播放页广播），并消除切集时历史重复写入
- **v3.1.245**：关于页改名"就AI听"并新增详细帮助；节目单长按支持"删除分段"；收录上一版本《歌曲检测密度门控》优化
- **v3.1.244**：歌曲检测加入密度门控（音乐窗占比≥30%），合并间隔放宽到 30s，最短歌曲 25s；修复一首歌被切成多段、总分段数偏多的问题
- **v3.1.243**：歌曲/片花检测从反向过零率判据改为"高响度+低谐波"判据，修复干净讲话被误判为歌曲
- 更早版本：实现就AI听三层分段、字幕生成、指纹识别、缓存管理、播放计划/历史等功能（详见 Git 历史）

## 构建说明

- 环境：Android Studio + NDK（arm64-v8a）、CMake
- 编译 Release：
  ```bash
  cd radioapp
  ./gradlew assembleRelease
  ```
- 产物：`app/build/outputs/apk/release/RadioApp-v<版本号>.apk`
- 注意：项目依赖完整 JDK 11（含 `jlink`）；若构建报 `jlink does not exist`，请安装
  `openjdk-11-jdk`（headless JRE 不包含 `jlink`）。

## 项目结构

```
app/src/main/java/com/radio/app/
├── activities/     播放页、设置入口、关键词管理、指纹管理等 Activity
├── fragments/      节目单、设置、首页、搜索等 Fragment
├── adapters/       各列表适配器（节目、分段、指纹、搜索结果等）
├── database/       SQLite 数据库助手（分段、字幕、指纹、缓存元数据）
├── models/         数据模型（Episode、VoiceSegment、Transcript 等）
├── services/       播放服务、字幕生成、指纹、YAMNet 等后台服务
├── utils/          分段生成器、音频分析与缓存、偏好管理等
└── widgets/        自定义控件
```
